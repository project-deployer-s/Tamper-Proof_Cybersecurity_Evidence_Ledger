Attack Demonstrations

Explore how the Evidence Ledger detects common cybersecurity attacks using ECDSA digital signatures and message verification.

1. Message Tampering

An attacker modifies a message after it has been signed. The original hash no longer matches the message.

2. Forged Digital Signature

An attacker signs a message using an unauthorized private key. The receiver's public key cannot verify the signature.

3. Replay Attack

An attacker attempts to submit a previously used message with the same nonce.

4. Expired Message

An attacker attempts to reuse a message with an expired timestamp.

5. Revoked Public Key

An attacker attempts to use a signing key that has already been revoked.

6. Ledger Tampering

Demonstrates how an attacker can modify a ledger entry and even recalculate the hash chain. The independent external anchor detects the rewritten chain.

Simulation Information

These demonstrations generate temporary cryptographic data. They do not modify registered users, real messages, database records, or the permanent evidence ledger.
